# Valkren

Valkren reúne tus juegos de Steam, Epic, EA, GOG y RetroBat en una sola biblioteca, con Modo TV para jugar con mando.

Este repositorio solo publica los instaladores para Windows. El código es privado.

## Instalar

1. Abre la [última versión](https://github.com/rmjourdan/valkren-releases/releases/latest).
2. Descarga `Valkren-Setup-<versión>.exe` y ábrelo. Se instala solo para tu usuario, sin permisos de administrador.
3. Windows puede mostrar «Windows protegió tu PC», porque el instalador todavía no está firmado. Elige **Más información → Ejecutar de todos modos**.

## Actualizaciones

Valkren busca versiones nuevas al abrirse y cada 6 horas. Las descarga sola y las instala al cerrar la app. También puedes buscarlas en **Ajustes → Ayuda y créditos**.

## Tus datos

Tu biblioteca, tus ajustes y tus claves se guardan en tu PC (`%APPDATA%\game-tracker`) y nunca se suben a ningún lado. Desinstalar Valkren no los borra.

Las claves de servicios (Steam, SteamGridDB, IsThereAnyDeal, etc.) son personales: cada persona carga las suyas en **Ajustes → Datos e imágenes**.
